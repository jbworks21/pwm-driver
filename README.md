# PWM Driver (STM32F407 / ARM Cortex-M4)

A bare-metal driver for TIM4_CH1, generating hardware PWM on PD12.
The demo fades an LED smoothly from off to full brightness and back,
while the CPU does essentially nothing — the waveform is generated by
silicon, not by a software loop.

Built from scratch — no HAL, no CMSIS, no vendor SDK. Every register
access is explicit and explained in the source comments.

## What This Teaches

- **Timer anatomy** — how `PSC`, `CNT`, and `ARR` produce a period
- **The frequency formula** — `f = fCK / ((PSC+1) × (ARR+1))`
- **Output compare mode** — the timer drives a pin by comparing `CNT` to `CCR`
- **PWM mode 1 vs mode 2** — which side of the comparison the pin is on
- **Preload (double-buffering)** — `OC1PE` and `ARPE` eliminate glitches
- **Forcing initial load** — why `EGR = UG` is needed before the first period
- **The `+1` subtlety** — `PSC` and `ARR` store "value minus one"

## Hardware

- **MCU:** STM32F407 (any board with TIM4_CH1 available on PD12)
- **Output:** PD12 — the built-in green LED on STM32F4-Discovery, or an
  external LED through a 330 Ω resistor to GND on other boards
- **Serial (optional):** PA2 (TX) → USB-UART adapter RX, GND → GND, **115200 8N1**

No external hardware is required on a Discovery board — the on-board
LED on PD12 is exactly the pin this driver targets.
